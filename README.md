# 暗影裂境 · Card Roguelike

一款受《炉石传说》×《杀戮尖塔》启发的**单文件网页卡牌肉鸽**游戏。选择职业，穿越三幕随机地图，收集卡牌与遗物，击败首领，构筑属于你的专属牌组。

![纯前端 · 零依赖](https://img.shields.io/badge/纯前端-零依赖-brightgreen) ![单文件](https://img.shields.io/badge/单文件-HTML/CSS/JS-blue) ![GitHub 许可证](https://img.shields.io/badge/许可证-MIT-orange)

## 🎮 玩法简介

- **四个职业**：法师 🧙 / 战士 ⚔️ / 猎人 🏹 / 圣骑士 🛡️，各有专属卡组、技能与卡牌池
- **三幕冒险**：黑暗森林 → 远古地牢 → 暗影裂境，地图随机生成
- **多种节点**：战斗 ⚔️ / 精英怪 / 事件 ❓ / 商店 💰 / 酒馆 🍺 / 宝箱 🎁 / 首领 👑（事件按幕加权，共 18 种）
- **三类难度**：简单 / 普通 / 困难（影响敌方血量、攻击力与起始手牌）
- **差异化敌方 AI**：激进（主攻英雄）/ 控制（优先清场）/ 法术 / 首领四种行为风格
- **永久强化**：通关或失败获得「裂境碎晶」，在裂境圣所升级全局属性
- **丰富关键字**：嘲讽 🛡 / 圣盾 ✨ / 冲锋 ⚡ / 风怒 🌀 / **吸血 🩸 / 剧毒 ☠ / 过载 ⚡** / 战吼 / 亡语
- **遗物系统**：被动遗物 + 主动宝藏，构筑流派

## 🚀 如何运行

直接双击打开 `index.html` 即可游玩（单文件、零依赖、无需服务器）。

如需使用本地服务器（推荐，避免个别浏览器限制）：

```bash
# Python
python -m http.server 8000
# 然后浏览器访问 http://localhost:8000

# 或 Node
npx serve .
```

## ⌨️ 操作说明

| 操作 | 说明 |
|---|---|
| 鼠标左键 | 选择 / 打出卡牌 / 结束回合 |
| 鼠标右键 / 长按（移动端） | 查看卡牌详情 |
| **鼠标悬停手牌（桌面端）** | 悬浮卡片信息提示 |
| **Enter / 空格** | 结束回合 |
| **Esc** | 取消当前目标选择 |
| 设置面板 | 音乐 / 音效 / **战斗动画开关** |

## 🛠 技术栈

- 纯 HTML + CSS + 原生 JavaScript（单文件，约 5000 行，无任何外部依赖）
- Web Audio API（程序化生成音乐与音效）
- `localStorage`（存档 / 设置 / 永久进度）
- 响应式布局（桌面端 + 移动端）
